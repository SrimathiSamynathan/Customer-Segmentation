👥 Customer Segmentation Dashboard  

Segment customers based on behavior and demographics using Machine Learning.

🚀 Live Demo
https://customer-segmentation2k26.streamlit.app/

🛠️ Tech Stack
- Python
- Streamlit
- Scikit-learn (K-Means Clustering)
- Plotly & Seaborn
- Pandas & NumPy

✨ Features
- 📊 Interactive cluster visualizations
- 🥧 Segment distribution pie chart
- 📈 Elbow method chart
- 🌐 3D scatter plot
- 🔮 Predict segment for new customer
- 📥 Download segmented CSV
- 🎨 Dark themed UI

📁 Dataset
Mall Customer Segmentation Dataset from Kaggle
